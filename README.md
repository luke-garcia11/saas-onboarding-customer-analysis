# Customer Onboarding & Churn Analysis

A business analysis case study investigating why customers onboard slowly at a fictional B2B SaaS company and how onboarding performance relates to first-year churn.

**Tools:** SQL (SQLite), Power BI, process mapping, project planning

**Status:** In progress

## Overview

This project analyzes onboarding performance for a fictional B2B SaaS company (Vantora Software) to understand what drives slow onboarding and whether it is associated with first-year churn. It will include SQL analysis, a Power BI dashboard, current- and future-state process maps, requirements, and a project plan.

## Dataset

The dataset contains 2,000 fictional customers who signed between July 2024 and June 2025. Each record includes segment, plan, ARR, sales rep, customer success manager, onboarding dates, support and training activity, engagement and satisfaction scores, and churn outcome.
